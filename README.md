# ClinicMind Practice

給臨床心理碩士生的刻意練習訓練系統。訓練工具，不供真實個案使用，也不取代督導。

## 狀態（2026-11-15）

| 部分 | 狀態 |
|---|---|
| 階段 1：走讀＋微技能練習（本機模式） | 完成，可部署 |
| 基礎階段 8 個模組內容（每個：走讀、30 題、示範回應） | 完成。模組 1–2 已審核；模組 3–8 待審核 |
| 階段 2：登入、雲端進度、督導後台 | 程式完成。需要 Supabase 專案才能啟用；4 個端到端測試尚未在真實後端執行 |
| 階段 3 Task 1：去識別化掃描器 `packages/deid/` | 完成 |
| 階段 3 其餘：報告上傳、Google Drive 存放、督導評閱 | 未開始 |
| 階段 4–6：AI 回饋、EFT、DBT | 未寫規格 |

測試：`npm run check`（260＋142 個測試）、`npm run e2e`（11 個通過，4 個需要後端而跳過）。

## 文件

| `content/REVIEW.md` | 內容審核登記 |

## 不可跳過的關卡

1. 臨床內容未經審核並登記 `content/REVIEW.md`，學生看不到。
2. 部署、花錢、對學生開放報告功能，都要專案擁有人批准。
3. 雲端模式對學生開放前，先在測試專案跑完 `docs/SETUP.md` 的隔離測試。
