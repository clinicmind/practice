# Client J：DBT 階段的貫穿個案（草稿）

狀態：草稿，待擁有人確認。確認前不寫任何走讀或練習題。
這份文件只給內容作者看，不對學生顯示。Client J 是為教學而虛構的人物。

## 0. 範圍（擁有人已於 2026-11-15 同意）

Client J 的目標行為**不包括危及生命的行為**。危及生命行為的評估和處理流程不在本工具範圍內，學生要在督導下按機構守則學習。每個模組的簡介都要寫明這一點。
走讀中，治療師在初期會平穩地問及自我傷害和自殺想法（和基礎階段的做法相同），J 的回答是沒有。之後不再展開。

## 2. 目標行為（依 DBT 的優先次序）

| 層級 | J 的情況 |
|---|---|
| 危及生命的行為 | 沒有。不在本工具範圍內 |
| 干擾治療的行為 | 衝突後缺席而不通知；遲到；深夜傳很長的訊息給治療師；說「我看這個治療也沒有用」 |
| 干擾生活品質的行為 | 情緒強烈時暴食；衝動消費；在訊息中和人激烈爭吵後封鎖對方；衝動辭職或推掉案子 |
| 需要增加的行為技能 | 情緒強烈時先停下來；說出需要而不是指控；忍受不確定 |

## 3. 生物社會理論的理解（作者用）

- **情緒敏感度**：從小反應快、反應強、平復得慢。
- **不認可的環境**：家人不壞，但對她的情緒的回應一貫是「你太誇張」「這有什麼好哭」。她要哭得很厲害，才有人理會。姊姊是「懂事的那個」。
- **學到了什麼**：自己的感受不可信；要升級到很大聲才會被聽見；被忽略等於被否定。
- **現在的循環**：感到被輕視 → 情緒迅速升高 → 衝動行為（暴食、封鎖、辭職）→ 短暫舒緩 → 羞愧和實際損失 → 更確信「我有問題」「沒有人受得了我」。

## 4. 一個可供行為鏈分析的事件（模組 3 用）

星期三下午，客戶回電郵：「這一版不太對，我們再想想。」沒有稱呼，沒有署名。
J 的想法：「他們覺得我很差。」→ 胸口發熱、手抖 → 打了一封很長的回覆又刪掉 → 把手機丟到沙發 → 叫了兩人份的外賣，二十分鐘吃完 → 稍微平靜 → 羞愧 → 傳訊息給客戶說「這個案子我不做了」→ 第二天沒有去會談。

這條鏈上有四個可以介入的環節，模組 3 和 4 會逐一使用。

## 5. 在治療關係中的樣子

- 開始時很投入，會說「你是第一個明白我的人」。
- 治療師一有她不喜歡的回應（例如結束時間到了、沒有即時回覆訊息），她會迅速轉為「你和其他人一樣」。
- 缺席之後回來，第一句常是挑戰：「你是不是想我不要再來？」
- 這些都是模組 6（干擾治療的行為）的材料。處理的方式是把它當成要解決的問題，而不是對治療師的攻擊。

## 6. 六個模組的弧線

| 模組 | 發生什麼 | 學生要看到的重點 |
|---|---|---|
| 1 `dbt-validation` | J 講述上一段治療怎樣結束。治療師向她說明生物社會理論，她第一次覺得「原來不是我壞」 | 認可的層次；認可不等於同意；怎樣解釋生物社會理論而不貼標籤 |
| 2 `dbt-commitment` | 談治療目標和約定。J 想要「不再這麼痛苦」，但不想放棄封鎖別人 | 承諾策略；讓個案自己說出改變的理由 |
| 3 `dbt-chain` | 對星期三的事件做行為鏈分析。J 起初覺得被審問 | 行為鏈的提問要具體而不帶指責；一邊分析一邊認可 |
| 4 `dbt-solutions` | 在鏈上找介入點；教一項技能；一次技能指導 | 解決方案由個案產生；技能要在會談中練，不只是講 |
| 5 `dbt-dialectics` | J 說「你要我改，就是說我現在這樣不行」。治療師要同時站在認可和改變兩邊 | 辯證的平衡；直率的溝通用在什麼時候 |
| 6 `dbt-tib` | J 缺席一次後回來，並說想停止治療 | 把干擾治療的行為當成目標行為處理；與個案商議 |

結局設定：部分改善。暴食的次數減少；能在情緒升高時停一下再回覆；缺席前會通知。人際關係仍然不穩，治療會繼續。

## 7. 寫作規則（在基礎階段的規則之上）

1. 不寫診斷名稱。不用任何診斷名稱來形容 J。
2. 不重現已出版的 DBT 技能講義和工作紙的內容。可以提到技能類別的名稱；技能的教導用自己的話寫，而且只教走讀需要的那一兩項。
3. J 不是「難纏的個案」。走讀的語氣要讓學生看到她的行為在她的處境下說得通。
4. 治療師至少有一次被 J 激怒而回應得不好，然後修正。
5. 暴食只描述到行為鏈分析需要的程度，不寫食物細節、熱量、體重。

## 8. 需你決定

1. 年齡、性別、職業可以嗎？我考慮過用男性個案來避開刻板印象，最後保留女性，因為暴食和關係中的升級在走讀中比較容易寫得具體。你可以改。
2. 目標行為的組合（暴食、衝動消費、封鎖和辭職、干擾治療的行為）是否合適？有沒有你想換掉的？
3. 模組 4 只教一至兩項技能。你希望是哪兩項？
4. 你的學生會不會同時在其他課程學完整的 DBT？如果會，這個階段可以更聚焦在「治療師怎樣說話」，少放理論。
