# 繁體中文版：工作說明

目標：應用介面和基礎階段 8 個模組都有繁體中文版。學生可在英文和繁中之間切換。進度兩種語言共用。

## A. 翻譯規則（內容和介面都適用）

1. 繁體中文。澳門和台灣讀者都讀得順。不用中國大陸用語：寫「資訊、影片、品質、網路」，不寫「信息、視頻、質量、網絡」。
2. 翻譯意思，不逐字對譯。個案說的話要像真人說的：短、有停頓、有「我不知道」。治療師的話要自然，不可像教科書。
3. 用標準書面中文。不用粵語口語字（唔、嘅、咗）。
4. 短句。一段一個意思。少用破折號。不堆疊「不是……而是……」。不用 emoji。
5. 不可新增或刪除臨床內容。英文版怎樣說，中文版就說同一件事。不可加入診斷名稱、藥物名稱。
6. 每個 `id`、`level`、`skill`、選項 `id`、`fit`、`speaker`、`type`、`slug`、檔名和 YAML 結構（包括錨點）都不可改動。只翻譯給人讀的文字欄位。
7. 英文版練習題中的人名（例如 Sam、Jo），改成不指向真實人物的稱呼（例如「阿森」「阿祖」）。K、M 保留字母：「K」「個案 M」。
8. `module.yaml` 的 `version` 從 `1.0.0` 開始，和英文版分開計算。

## C. 內容檔案

`content/zh-Hant/stages/foundations/` 的結構和 `content/en/stages/foundations/` 完全相同：`stage.yaml` 和 8 個模組各四個檔。

## D. 程式

1. 語言：`'en' | 'zh-Hant'`。存在 `localStorage['cm.practice.locale']`。沒有紀錄時，瀏覽器語言以 `zh` 開頭就用繁中，否則用英文。
2. 頁首有切換按鈕，顯示另一種語言的名稱（`繁體中文`／`English`）。切換後 `<html lang>` 同步更新。
3. `src/i18n/zh-Hant.ts` 的鍵必須和 `en.ts` 完全一致，由型別檢查保證。
4. 建置腳本同時處理兩種語言。繁中模組的 id、level、skill、決策點、選項 id 和 `fit` 必須和英文版逐一相同，否則建置失敗並指出差異。
5. 審核按語言分開（`content/REVIEW.md` 的 `locale` 欄）。繁中模組未審核或不存在時，學生看到英文版，並顯示一行提示：`此模組的中文版尚未提供，現在顯示英文版。`
6. 進度以題目 id 為鍵，所以兩種語言共用進度。切換語言不可遺失輸入中的文字。
7. 督導後台的介面文字也要有繁中。`copied-model` 的偵測要同時對照兩種語言的示範回應。
